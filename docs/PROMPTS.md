# 추천 프롬프트

Vitalog MCP를 Claude에 처음 연결한 뒤 바로 붙여 넣어 쓸 수 있는 프롬프트 모음입니다. 건강 지표를 잘 모르는 사용자를 기준으로, 각 지표의 의미를 먼저 설명하고 최근 추세를 해석하도록 만들었습니다.

## 사용 전에

- 연결 직후에는 [1. 첫 인사: 내 데이터 파악하기](#1-첫-인사-내-데이터-파악하기)부터 실행합니다. 어떤 데이터가 얼마나 쌓였는지 알아야 다음 프롬프트의 기간을 맞출 수 있습니다.
- 프롬프트의 "최근"은 데이터가 마지막으로 동기화된 날짜 기준입니다. Claude는 오늘 날짜를 모를 수 있으므로 프롬프트마다 마지막 데이터 날짜를 먼저 확인하도록 적어 두었습니다.
- 이 서비스는 의료 진단 도구가 아닙니다. 해석은 참고용이고, 수치가 걱정되면 의사와 상담해야 합니다.
- 지표 값이 비어 있으면(예: 워치를 안 찬 기간) Claude가 "데이터 없음"으로 알려 주도록 되어 있습니다. 없는 값을 추측하지 않게 하려면 각 프롬프트의 마지막 줄을 지우지 마세요.

## 1. 첫 인사: 내 데이터 파악하기

```
Vitalog 도구로 내 건강 데이터에 어떤 종류가 있는지 확인해 줘.
각 데이터가 언제부터 언제까지 쌓였는지, 건강 지표를 처음 보는 사람도 이해할 수 있게 표로 정리해 줘.
그다음 내 데이터로 할 수 있는 분석 5가지를 추천해 줘.
```

## 2. 핵심 지표 3종 한 번에 이해하기

VO2max, 안정 시 심박수, 심박 변이도를 처음 보는 사용자를 위한 기본 프롬프트입니다.

```
내 VO2max, 안정 시 심박수(resting_heart_rate), 심박 변이도(heart_rate_variability_sdnn)를 분석해 줘.

먼저 list_metrics로 이 세 가지 데이터가 언제부터 언제까지 있는지 확인하고, 마지막 데이터 날짜를 "오늘"로 삼아 줘.

각 지표마다 아래 순서로 설명해 줘.
1. 이 지표가 무엇이고 몸의 어떤 상태를 보여 주는지 쉬운 말로 설명 (비유 환영)
2. 값이 높을 때와 낮을 때 각각 무엇을 뜻하는지
3. 내 최근 4주 평균과 직전 4주 평균 비교, 그리고 최근 6개월의 월별 추이 (metric_trend 사용)
4. 추세가 좋아지는 중인지, 유지인지, 나빠지는 중인지 한 줄 판단과 그렇게 본 근거 숫자
5. 이 추세의 흔한 원인 후보 (운동량, 수면, 컨디션, 계절, 측정 방식 변화 등)

마지막에 세 지표를 합쳐서 지금 내 몸의 컨디션을 3문장으로 요약해 줘.
데이터가 없거나 부족한 기간은 추측하지 말고 "데이터 없음"이라고 말해 줘.
```

### 지표 설명 (참고용)

프롬프트의 답이 맞는지 가늠할 때 참고하세요. 값은 사람마다 크게 다릅니다. 남과 비교하기보다 내 과거와 비교하는 편이 의미 있습니다.

| 지표 | `type` 이름 | 단위 | 의미 | 좋은 방향 |
| --- | --- | --- | --- | --- |
| VO2max | `vo2_max` | mL/kg/min | 몸이 쓸 수 있는 산소의 최대량. 유산소 체력의 대표 지표입니다. 애플워치가 야외 걷기, 달리기, 하이킹 중 추정하므로 자주 갱신되지 않습니다. | 높을수록 좋음. 수 주~수 개월에 걸쳐 천천히 변함 |
| 안정 시 심박수 | `resting_heart_rate` | 회/분 | 쉬고 있을 때 심장이 뛰는 횟수. 심장이 효율적일수록 낮습니다. | 낮을수록 좋음. 평소보다 5회 이상 올라 있으면 피로, 과훈련, 수면 부족, 컨디션 저하, 감기 같은 신호일 수 있음 |
| 심박 변이도(SDNN) | `heart_rate_variability_sdnn` | ms | 심장 박동 사이 간격이 얼마나 들쭉날쭉한지. 자율신경이 회복 쪽으로 기울어 있을수록 큽니다. | 내 평소 값보다 높으면 회복 양호, 낮으면 스트레스나 피로. 하루 값은 들쭉날쭉하니 주 평균으로 볼 것 |

세 지표 모두 하루 단위 값이 아니라 며칠에서 몇 주의 추세로 읽어야 합니다. 하루 이틀 튀는 값에는 의미를 두지 않는 것이 좋습니다.

## 3. 지표별 상세 프롬프트

### VO2max만 자세히

```
내 VO2max 변화를 분석해 줘.
list_metrics로 마지막 데이터 날짜를 확인하고, 전체 기간의 월별 추이를 metric_trend로 가져와 줘.
VO2max가 뭔지 운동을 안 하는 사람도 알 수 있게 설명하고,
내 값이 처음 기록 대비 얼마나 변했는지, 최근 3개월은 오르는지 내리는지 알려 줘.
같은 기간의 러닝, 걷기 운동 횟수(workouts)와 비교해서 운동량과 관련이 있어 보이는지도 말해 줘.
VO2max는 측정 빈도가 낮으니 측정 횟수가 적으면 그 점도 알려 줘.
```

### 안정 시 심박수만 자세히

```
내 안정 시 심박수 추세를 분석해 줘.
최근 90일을 주 단위로 보여 주고, 가장 낮았던 주와 가장 높았던 주를 짚어 줘.
안정 시 심박수가 뭔지, 왜 낮을수록 좋다고 하는지 쉽게 설명해 줘.
평소보다 눈에 띄게 높았던 주가 있으면 그 주의 수면 시간(sleep_summary)과 운동량을 같이 보고 원인 후보를 알려 줘.
```

### 심박 변이도만 자세히

```
내 심박 변이도(HRV, SDNN) 추세를 분석해 줘.
HRV가 뭔지, 왜 "높을수록 좋다"고 하는데 남과 비교하면 안 되는지 쉽게 설명해 줘.
최근 90일을 주 단위로 보여 주고, 내 평소 범위(전체 기간 평균 ± 변동)를 기준으로 최근이 높은지 낮은지 알려 줘.
HRV가 낮았던 주의 수면 시간과 운동 강도를 같이 보고 연관이 있어 보이는지 말해 줘.
```

## 4. 종합 프롬프트

### 이번 주 컨디션 점검

```
내 이번 주 컨디션을 점검해 줘.
마지막 데이터 날짜를 기준으로 최근 7일을 가져와서,
걸음 수, 수면(총 시간과 깊은 수면), 안정 시 심박수, HRV를 지난 4주 평균과 비교해 줘.
평소보다 좋은 점과 나쁜 점을 각각 두세 개씩 짚고, 오늘 쉬는 게 좋을지 운동해도 될지 참고 의견을 줘.
각 용어는 처음 나올 때 한 줄로 풀어서 설명해 줘.
```

### 최근 3개월 변화 리포트

```
최근 3개월 동안 내 몸에 어떤 변화가 있었는지 리포트로 만들어 줘.
VO2max, 안정 시 심박수, HRV, 체중(body_mass), 걸음 수, 수면 시간을 월별 추이로 가져와서
표 하나와 "좋아진 것 / 그대로인 것 / 나빠진 것" 세 묶음으로 정리해 줘.
어려운 용어는 처음 나올 때 풀어서 설명하고, 숫자 근거를 꼭 붙여 줘.
마지막에 다음 달에 해볼 만한 행동 한두 가지를 제안해 줘.
```

### 운동과 회복의 관계

```
내 운동과 회복 지표가 어떻게 연결되는지 알고 싶어.
최근 6개월 동안 운동을 많이 한 주와 적게 한 주를 나누고(workouts),
각 주의 안정 시 심박수, HRV, 수면 시간이 어떻게 달랐는지 비교해 줘.
운동량이 늘 때 내 몸이 어떻게 반응하는 편인지, 회복에 며칠쯤 걸리는 것 같은지 알려 줘.
```

## 5. 후속 질문 예시

위 답변을 받은 뒤 이어서 물어보기 좋은 질문입니다.

- "방금 설명에서 HRV가 뭔지 더 쉽게 다시 설명해 줘."
- "내 안정 시 심박수가 가장 낮았던 시기에 나는 뭘 하고 있었는지 운동과 수면 기록으로 추측해 줘."
- "이 추세가 계속되면 3개월 뒤 어떻게 될 것 같아? 단정하지 말고 가능성으로 말해 줘."
- "의사에게 보여 줄 수 있게 최근 6개월 요약을 한 장으로 정리해 줘."

## 프롬프트를 고칠 때

- 지표 이름은 `list_metrics`가 돌려주는 `daily_stats`의 `type` 값을 그대로 씁니다. 서버에 새 지표가 생기면 이 문서의 표와 프롬프트에도 반영합니다.
- 프롬프트에 기간을 박아 넣지 말고 "마지막 데이터 날짜 기준 최근 N일"로 씁니다. 동기화가 멈춘 뒤에도 빈 구간을 보지 않게 하기 위해서입니다.
- 실제 건강 수치는 이 문서에 넣지 않습니다.
